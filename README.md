# 東京学芸大学 空き教室検索（2026年度・非公式）

東京学芸大学の2026年度シラバス・時間割データをもとに、開講期・曜日・時限から空き教室を検索する静的Webアプリです。

- 「現在から探す」で日本時間に基づく開講期・曜日・時限を選択。
- 教室ごとの利用状況や、その後の授業を表示。
- 「自分の時間割」では授業データからの検索・手入力・編集・削除に対応。現在の授業と今後1週間の授業を表示。
- PWAとしてのインストール、キャッシュによるオフライン利用、登録授業の通知を提供。通知の更新は画面を開いている間が中心で、完全終了中の自動更新は保証されません。
- 空室の実測や予約機能ではありません。休講・補講・教室変更・授業振替等は反映されません。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `styles.css` | ページ・表示スタイル |
| `app.js` | 空き教室検索、開講期・日本時間の処理 |
| `timetable.js` | 個人時間割、次の授業、JSON入出力 |
| `notification-model.js` / `pwa.js` | 通知の計算、PWA・通知操作 |
| `sw.js` | キャッシュ、通知表示 |
| `data/` | 2026年度の教室・授業JSON |

時間割は各端末・ブラウザのlocalStorage（`tgu-personal-timetable-2026-v1`）へ保存します。個人時間割の保存・移行用サーバーはありません。サイトにはアクセス解析としてGoogle Analyticsの設定があります。

## 時間割を別端末へ移す

1. 移行元の「自分の時間割」→「登録・編集」を開く。
2. 「時間割を別の端末へ移す・バックアップ」を開き、「JSONを書き出す」を押す。
3. 保存した `tgu-timetable-2026.json` を移行先端末へ送る。
4. 移行先で同じサイトを開き、同じ画面の「JSONを読み込む」でファイルを選ぶ。
5. 件数と置き換え内容を確認して読み込む。

全学期の登録授業をまとめて移します。既存の時間割は置き換わるため、必要なら先に書き出してください。端末間での自動同期は行いません。通知設定は移行対象外です。JSONには授業名・教室が含まれます。

### ファイル形式

```json
{
  "format": "tgu-personal-timetable",
  "version": 1,
  "academicYear": 2026,
  "exportedAt": "2026-11-11T00:00:00.000Z",
  "entries": [
    { "id": "example-1", "term": "秋学期", "day": "月", "period": 2, "name": "教育学", "room": "N203" }
  ]
}
```

読み込み時に形式・バージョン・年度・授業の各項目・IDの重複を検証します。上限は1MB・1,000件です。不正なファイル、キャンセル、保存失敗では既存データを変更しません。空の時間割も確認後に読み込めます。

## 確認

Node.jsの標準機能のみで入出力の回帰テストを実行できます。

```sh
node --test tests/timetable-transfer.test.cjs
node --check timetable.js
node --check sw.js
```

テストでは書き出し・復元、不正データ、件数・容量上限、キャンセル、空データ、保存失敗を確認します。実機ブラウザのダウンロードUIやPWA更新は別途確認してください。

公開時は静的ファイルを既存の配信先へ反映します。今回、`index.html` の時間割スクリプトURLと `sw.js` のキャッシュ番号を更新しています。
